# Electricity_Bill_Calculator


## Description

A responsive web application developed using **PHP, HTML, CSS, and JavaScript** to calculate electricity bills based on units consumed.

## Electricity Rates

* First 50 units: ₹3.50/unit
* Next 100 units: ₹4.00/unit
* Next 100 units: ₹5.20/unit
* Above 250 units: ₹6.50/unit

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* XAMPP

## How to Run

1. Install and open XAMPP.
2. Start **Apache**.
3. Place the project folder inside `htdocs`.
4. Open:
   `http://localhost/Electricity-Bill-Calculator/`
5. Enter the units consumed and click **Calculate Bill**.

## Features

* Simple and responsive design
* Automatic bill calculation
* User-friendly interface
* Unit-wise electricity rates
